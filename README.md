# Cat Handy

Storefront and admin UI for Cat Handy, built from the Cat Handy design canvas with Vite and React.

```bash
npm install
npm run dev
```

Storefront at `/`, admin at `/admin`. There is no backend yet: the cart and last order live in `localStorage` (`src/lib/cart.js`), and catalog, account, order tracking and admin screens use sample data.
